# REST API Documentation

The FastAPI backend exposes endpoints used by the Next.js investigation workspace.

## 1. Authentication

### `POST /api/auth/login`
- **Purpose**: Authenticates users and returns a session token.
- **Parameters**: `username`, `password` (JSON body)
- **Response**: `{ "token": "jwt...", "user": {...} }`

## 2. Data Ingestion & Pipeline Status

### `POST /api/upload`
- **Purpose**: Accepts multipart file uploads for Bank, CDR, IPDR, and NCRP datasets.
- **Parameters**: `file` (multipart/form-data)
- **Response**: `{ "status": "success", "file_id": "...", "detected_type": "SBI_PDF" }`

### `GET /api/pipeline/status`
- **Purpose**: Retrieves the real-time parsing, normalization, and fusion progress of the uploaded files.
- **Response**: `{ "state": "FUSION_COMPLETE", "parsed_records": 12040, "errors": 2 }`

## 3. Intelligence & Fused Data

### `GET /api/data/fused`
- **Purpose**: Retrieves the canonical fused event log (timeline view).
- **Parameters**: `limit` (default: 100), `offset` (default: 0), `type_filter` (optional)
- **Response**: Array of Unified Event objects.

### `GET /api/data/anomalies`
- **Purpose**: Retrieves all flagged transactions and behavioral alerts generated by the Risk Engine.
- **Response**: Array of Anomaly objects containing `score`, `rule_triggered`, and `evidence`.

### `GET /api/data/graph`
- **Purpose**: Returns the NetworkX-generated topology for money flow and communication hops.
- **Response**: `{ "nodes": [...], "edges": [...] }`

## 4. Entity Search & Dossier

### `GET /api/entities/search`
- **Purpose**: Global search across all canonical identifiers (phones, IPs, accounts).
- **Parameters**: `q` (query string)
- **Response**: Array of matching entity summaries.

### `GET /api/entities/dossier/{entity_id}`
- **Purpose**: Retrieves a comprehensive intelligence dossier for a specific entity.
- **Response**: `{ "entity": {...}, "related_events": [...], "risk_score": 0.85 }`

## 5. Investigative Copilot

### `POST /api/copilot/query`
- **Purpose**: Submits a natural language query to the Groq-powered RAG system.
- **Parameters**: `{ "query": "Show all transfers from account X to Y", "language": "en" }`
- **Response**: `{ "answer": "...", "evidence_used": [...], "sql_trace": "..." }`

## 6. Reporting

### `GET /api/reports/generate`
- **Purpose**: Triggers generation of the final forensic dossier / STR.
- **Parameters**: `format` (pdf/json)
- **Response**: PDF binary stream or JSON structure.
