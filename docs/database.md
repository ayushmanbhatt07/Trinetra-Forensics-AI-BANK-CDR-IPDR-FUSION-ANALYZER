# Storage and Database Architecture

Tri-Netra Forensics utilizes a high-performance **SQLite architecture with Write-Ahead Logging (WAL)** and in-memory caches, optimized for sub-millisecond query execution, zero-dependency deployment, and robust session persistence.

---

## 1. Relational SQLite Store (`backend/store.py`)

The primary database lives at `data/backend.db` and manages persistent records across server restarts and user sessions:

* **Write-Ahead Logging (`PRAGMA journal_mode=WAL`)**: Enables concurrent readers without blocking write transactions.
* **Persistent Schemas**:
  - `users`: User authentication, PBKDF2-HMAC-SHA256 password hashes, salt, roles (`admin`, `officer`), and timestamps.
  - `bundle`: Persistent JSON payloads for ingested datasets (`bank`, `cdr`, `ipdr`, `subscribers`, `complaints`, `entities`, `files`).
  - `pipeline_jobs`: Tracks asynchronous pipeline execution status (`PARSING`, `FUSING`, `SCORING`, `GRAPHS`, `READY`) with stage flags.
  - `investigations`: Investigation workspaces, notes, status, and metadata.
  - `findings`: Tagged evidence, severe flags, and dossier attachments.

---

## 2. In-Memory Co-Pilot Relational Database (`investigative_copilot/db_builder.py`)

For high-speed natural language analysis and Text-to-SQL execution:
* **Relational Schema**: Data from the ingested bundle is compiled into relational SQLite tables:
  - `bank_transactions` (with indexes on `account_no`, `receiver_account`, `sender_phone`, `receiver_phone`, `date`)
  - `cdr_calls` (with indexes on `caller_msisdn`, `receiver_msisdn`, `call_date`)
  - `ipdr_sessions` (with indexes on `msisdn`, `source_ip`, `start_date`)
  - `ncrp_complaints` (with indexes on `account_no`, `mobile_no`, `ack_no`)
* **Sub-Millisecond Execution**: Text-to-SQL queries generated by Groq LLaMA 3.3 70B execute in `< 1ms` against local indexed tables.

---

## 3. Advantages of the SQLite Architecture

1. **Zero External Infrastructure**: No external database containers, network hops, or connection pooling overhead required.
2. **Deterministic Durability**: All ingested cases and forensic analysis survive restarts and container redeployments.
3. **Atomic Concurrency**: Thread-safe with connection-level locks and WAL concurrency.
